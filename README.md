Expense Tracker Dashboard

A modern and responsive Expense Tracker Dashboard built using React, Tailwind CSS, and Chart.js.

Features

   Add Income and Expenses
   Delete Transactions
   Real-time Balance Calculation
   Expense Analytics Pie Chart
   Local Storage Support
   Responsive Dashboard UI
   Modern Fintech Design

Tech Stack

   React
   Tailwind CSS
   Chart.js
   Vite
   JavaScript

Future Improvements

- Dark/Light Mode
- Firebase Backend
- Authentication
- PDF Export
- Monthly Reports
